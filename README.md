# ETC-PFL-Federated-Learning

This repository implements a **two-phase Personalized Federated Learning framework**
for **Encrypted Traffic Classification (ETC)** under **Non-IID multi-domain SDN environments**.

## Key Features
- Federated Learning with Flower
- Siamese Network for feature extraction
- Two-phase training:
  1. Federated contrastive representation learning
  2. Local personalized classification
- Supported FL algorithms:
  - FedAvg
  - FedProx
  - MOON
  - FedCoSR
- Feather-based encrypted traffic dataset
